Frequently Asked Questions

My RAW files aren't matching.
The JPG and RAW files must share the same base filename — for example IMG_0001.JPG and IMG_0001.ARW. Capitalization does not matter.
I got an error while copying.
Check the error code (RC-xxxx) and the suggested fix shown in the log. If the problem continues, use Export Log (⌘E) and email us the ZIP file — it helps us diagnose quickly.
Does it work with external drives and NAS?
Yes. exFAT, NTFS and HFS+ external drives as well as network drives are supported, including non-English filenames.
Can my original files be damaged?
The RAW source folder is only ever read. When overwriting, the app uses a safe atomic replace via temporary files and backups, so existing files are never corrupted. You can also enable SHA-256 verification to confirm every copy.
How does the free trial work?
All features are available free for 10 days. After that, a single in-app purchase unlocks the app permanently. If you reinstall or switch Macs, use “Restore Purchases”.

よくある質問

コピー中にエラーが出ました。
ログに表示されるエラーコード（RC-xxxx）と対処方法をご確認ください。解決しない場合は「ログを書き出す」（⌘E）で作成したZIPファイルをメールでお送りいただければ、すぐに確認いたします。

RAW原本フォルダは読み取りのみです。上書き時も一時ファイルとバックアップを経由する安全な置換方式のため、既存ファイルが壊れることはありません。SHA-256検証を有効にすれば、コピー結果を1件ずつ確認できます。
